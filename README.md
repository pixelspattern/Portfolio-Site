# Responsive design (fluid design + media queries)



| Mobile | css/mobile.css | up to 480px | Most phones are about 360 to 430px wide |
| Tablet | css/tablet.css | 481px to 960px | Covers tablets in portrait and small laptop windows |
| Laptop | css/laptop.css | 961px and up | Standard laptop and desktop screens |

What changes at each size: [e.g. wrapper width, nav links stack on mobile,
banner padding, profile photo size 200px / 160px / 120px.

# Gradients

- Linear gradient (top to bottom): the `header` background, in all three stylesheets,
  on every page: linear-gradient(#264653, #2a9d8f).
- Angled linear gradient (135deg): the #banner div, in all three stylesheets,
  used on the Home, About, Projects and Contact pages:
  linear-gradient(135deg, #e9c46a, #f4a261).
